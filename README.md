# Maligai WhatsApp AI Bot

Node.js backend for a grocery shop WhatsApp chatbot.

## Features

- Grocery ordering
- Price lookup
- Offers
- Order status
- Automatic bill calculation
- WhatsApp webhook
- Local API testing

## Install

npm install

## Run

npm start

## Test

POST:

/api/chat

JSON:

{
  "message": "2 kg rice, 1 kg sugar, 1 litre oil"
